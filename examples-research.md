## Конкуренты и примеры

Дата проверки: 4 ноября 2026. Ниже семь действующих авторских сайтов и три концептуальных референса с дизайн-платформ. Концепты не следует считать доказательством коммерческой эффективности. Проверка выполнена по доступным страницам и их текстовому содержимому; сложные визуальные эффекты не тестировались в браузере. Предложения по стилю и шрифтам — авторская адаптация для проекта, а не установленный стек оригинала.

### Дополнительный полноценный пример

**[Jhey Tompkins](https://www.jhey.dev/)** — действующий авторский сайт дизайнера и инженера. Цепляет обещанием объяснять сложные идеи через интерфейсы и прототипы; опыт и ссылки на эксперименты служат доказательством. На доступной странице подтверждены: имя и роли, короткое описание практики, прототипы, выступления, Index, email, AMA и социальный профиль. Для адаптации рекомендую компактную авторскую подачу, акцент на работающие демо, Inter + IBM Plex Mono; это предложение для проекта, не определение реальных шрифтов сайта.

Уточнение Dribbble: для Sajon найдена [прямая карточка работы](https://dribbble.com/shots/25996690-Developer-Portfolio-Landing-Page); она публикует палитру #D2CCB7, #F7F6F4, #081612 и дополнительные оттенки. Полная композиция секций текстовым инструментом не подтверждается.

### Вывод по примерам

Для лендинга «сайты, приложения и ИИ-агенты» наиболее полезна комбинация ясности Dennis, продуктовых доказательств Emil и спокойной иерархии Brittany. Интерактив Bruno пригоден как небольшой демонстрационный модуль, но не как обязательный способ навигации. Dribbble даёт идеи композиции, Behance — материал для дальнейшего визуального просмотра; ни одна из этих площадок сама по себе не подтверждает конверсию.

Для русской версии проверить кириллицу и лицензию выбранного семейства перед внедрением. Достаточно одного основного шрифта и одного моноширинного акцента; предложенные пары не нужно использовать одновременно.

Исследовательский промпт: «Исследуй интернет: 7–10 реальных портфолио лендингов digital designer/developer, сайты/apps/AI. Обязательно Awwwards, Dribbble, Behance. Для каждого цепляющее, секции, стиль, рекомендованные шрифты (не выдавай рекомендации за определенные реальные). Ссылки источников, честные ограничения доступа. Пиши по-русски в examples-research.md в cwd. Используй web tools через functions discovery. Самостоятельная исследовательская задача без разработки.»
